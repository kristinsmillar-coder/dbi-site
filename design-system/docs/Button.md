---
category: Actions
---

Mono uppercase, square corners, never rounded, never shadowed. Red `primary` marks exactly one action per screen; `gold` is reserved for the award or the secondary program; `outline` is everything else. Compose side-by-side inside `<Actions>`.

```tsx
<Actions>
  <Button variant="primary" href="/join">Apply to DBI</Button>
  <Button href="/course">See what a session is like</Button>
</Actions>
```
